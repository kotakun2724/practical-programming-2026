## ① アルゴリズム系

> C/C++またはPythonで、基本的なアルゴリズムを習得するコース

- 「問題を解く力」を鍛えるコースです。AOJなどの問題をステップbyステップで解いていきます。
- 並べ替え（ソート）や探索、計算量の考え方など、プログラミングの土台になる考え方を学びます。
- 「じっくり考えて答えにたどり着く」のが好きな人におすすめです。

:::tip[ミニ演習：Fizz Buzz（やってみよう）]
有名な **Fizz Buzz** 問題に挑戦してみましょう。紙やエディタに、日本語の手順（アルゴリズム）でもコードでもOKです。

**ルール**：1 から 20 までの数を順番に出力する。ただし、

- 3 の倍数のときは、数のかわりに `Fizz`
- 5 の倍数のときは、数のかわりに `Buzz`
- 3 と 5 の両方の倍数（= 15 の倍数）のときは `FizzBuzz`
- それ以外はその数をそのまま出力

```text
期待する出力：
1, 2, Fizz, 4, Buzz, Fizz, 7, 8, Fizz, Buzz,
11, Fizz, 13, 14, FizzBuzz, 16, 17, Fizz, 19, Buzz

ヒント：繰り返しで 1 つずつ数を調べ、
「3で割った余り」「5で割った余り」が 0 かどうかで場合分けする。
15の倍数（FizzBuzz）の判定を先に書くのがコツ。
```

<details>
<summary>解答例（C / Python）</summary>

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 20; i++) {
        if (i % 15 == 0) {
            printf("FizzBuzz\n");
        } else if (i % 3 == 0) {
            printf("Fizz\n");
        } else if (i % 5 == 0) {
            printf("Buzz\n");
        } else {
            printf("%d\n", i);
        }
    }
    return 0;
}
```

```python
for i in range(1, 21):
    if i % 15 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)
```

</details>
:::
