AOJの使い方と配列・ループの基礎

このページでは、演習で使う AOJ の使い方と、アルゴリズムを書くために必要な 配列とループの基礎を確認します。前期を履修していない人は、まずここをしっかり押さえましょう。

AOJとは​

AOJ（Aizu Online Judge） は、会津大学の渡部有隆教授が開発したプログラミング問題のオンライン採点システムです。 提出したプログラムを自動で採点してくれるので、「正しく動くコードが書けたか」をその場で確認できます。

C言語、C++、Python、Java、JavaScript などさまざまな言語に対応しています。本授業では主に C言語 を使います。

本授業でのAOJの使い方​

  1. AOJ にアクセスし、アカウントを作成・ログインする
  2. 今回は ALDS1（アルゴリズムとデータ構造入門） コースの問題を解いていきます
  3. 問題文の Input / Output 欄をよく読み、入出力の形式を確認する
  4. コードを書いたら「提出（Submit）」する。「試す（Run）」は動作確認用です
  5. 結果が AC（Accepted） になれば正解です
判定結果の意味
結果意味
AC (Accepted)正解
WA (Wrong Answer)出力が間違っている
TLE (Time Limit Exceeded)実行時間オーバー（計算量が大きすぎる）
RE (Runtime Error)実行時エラー（配列の範囲外アクセスなど）
CE (Compile Error)コンパイルエラー（文法ミス）

入力の受け取り方（C言語）​

AOJ の問題は「標準入力」からデータを読み込みます。C言語では scanf を使います。

#include <stdio.h>

int main(void) {
    int n;
    scanf("%d", &n);        // 整数を1つ読み込む

    int a, b;
    scanf("%d %d", &a, &b); // 整数を2つ読み込む

    printf("%d\n", a + b);  // 結果を出力
    return 0;
}
出力形式に注意

AOJ は出力形式に厳密です。余計な空白や改行があると WA になります。 問題文の Output 欄をよく読んで、スペースや改行の位置を合わせましょう。

配列​

同じ型のデータをまとめて扱うのが配列です。n 個の整数を読み込む典型的な書き方は次の通りです。

#include <stdio.h>

int main(void) {
    int n;
    scanf("%d", &n);

    int a[100];                  // 最大100個の整数を入れる配列
    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);      // a[0], a[1], ..., a[n-1] に読み込む
    }

    // 空白区切りで出力
    for (int i = 0; i < n; i++) {
        if (i > 0) printf(" ");
        printf("%d", a[i]);
    }
    printf("\n");
    return 0;
}
配列の添字は 0 から

要素数 n の配列 a で使えるのは a[0] 〜 a[n-1] です。 a[n] にアクセスすると範囲外となり、AOJ では RE の原因になります。

ループ​

繰り返し処理には for 文と while 文があります。

// for 文: 回数が決まっているとき
for (int i = 0; i < n; i++) {
    // n 回繰り返す
}

// while 文: 条件が成り立つ間ずっと
int i = 0;
while (i < n) {
    i++;
}

アルゴリズムの多くは「配列をループで走査して、条件に応じて値を更新する」という形で書けます。 たとえば配列の最大値を求める処理は、配列を1回なめるだけです。

int max = a[0];
for (int i = 1; i < n; i++) {
    if (a[i] > max) max = a[i];  // より大きい値が来たら更新
}
printf("%d\n", max);

この「配列を1回走査して値を更新する」パターンに慣れると、次に学ぶ計算量の話が理解しやすくなります。
