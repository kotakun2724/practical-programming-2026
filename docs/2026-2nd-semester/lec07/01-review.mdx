# 前回課題解説

このページでは、第6回の必須課題 **ALDS1_12_B / ALDS1_12_C** の解説と解答コードをまとめます。

## ALDS1_12_B: Single Source Shortest Path I

### 方針

`n <= 100` なので、**隣接行列**と `O(V^2)` のダイクストラ法で解けます。

1. `d[0] = 0`、それ以外を `INF` にする
2. 未確定の頂点のうち `d` が最小の頂点 `u` を `for` 文で探し、確定する
3. `u` から出る辺で緩和する（`d[u] + M[u][v] < d[v]` なら更新）
4. これを `n` 回（または選べる頂点がなくなるまで）繰り返す

:::warning[「辺なし」の表し方]
この問題には重み `0` の辺があります。「辺なし」を `0` にすると区別できないので、`-1` で表します。
:::

### 解答コード（C）

```c
#include <stdio.h>

#define INF 2000000000

int n;
int M[100][100];
int d[100];
int done[100];   /* 1: 確定済み */

int main(void) {
    scanf("%d", &n);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++) M[i][j] = -1;   /* -1: 辺なし */

    for (int i = 0; i < n; i++) {
        int u, k;
        scanf("%d %d", &u, &k);
        for (int j = 0; j < k; j++) {
            int v, c;
            scanf("%d %d", &v, &c);
            M[u][v] = c;
        }
    }

    for (int i = 0; i < n; i++) d[i] = INF;
    d[0] = 0;

    for (int step = 0; step < n; step++) {
        /* 未確定の頂点のうち d が最小のものを探す */
        int u = -1;
        for (int i = 0; i < n; i++) {
            if (!done[i] && d[i] != INF && (u == -1 || d[i] < d[u])) u = i;
        }
        if (u == -1) break;   /* もう到達できる頂点がない */
        done[u] = 1;

        /* u から出る辺で緩和 */
        for (int v = 0; v < n; v++) {
            if (M[u][v] != -1 && d[u] + M[u][v] < d[v]) {
                d[v] = d[u] + M[u][v];
            }
        }
    }

    for (int i = 0; i < n; i++) printf("%d %d\n", i, d[i]);
    return 0;
}
```

### 例（サンプル入力）

```
5
0 3 2 3 3 1 1 2
1 2 0 2 3 4
2 3 0 3 3 1 4 1
3 4 2 1 0 1 1 4 4 3
4 2 2 1 3 3
```

頂点 0 から順に確定していくと、`d = [0, 2, 2, 1, 3]` になります。

| 確定する頂点 | d[0] | d[1] | d[2] | d[3] | d[4] |
|:---|---:|---:|---:|---:|---:|
| 0 | **0** | 2 | 3 | 1 | ∞ |
| 3 | **0** | 2 | 2 | **1** | 4 |
| 1 | **0** | **2** | 2 | **1** | 4 |
| 2 | **0** | **2** | **2** | **1** | 3 |
| 4 | **0** | **2** | **2** | **1** | **3** |

## ALDS1_12_C: Single Source Shortest Path II

### 方針

`n <= 10000`, `|E| < 500000` なので、隣接行列（`10000 × 10000`）も `O(V^2)` も使えません。

- グラフは `head / to / cost / nxt` の配列で作る**隣接リスト**で持つ
- 「`d` が最小の頂点」は**二分ヒープ**から取り出す
- 取り出した距離が `d[u]` より大きければ、**古い情報**なので読み飛ばす

### 解答コード（C）

```c
#include <stdio.h>

#define MAXV 10000
#define MAXE 500000
#define INF 2000000000

/* 重み付きの隣接リスト */
int head[MAXV];
int to[MAXE], cost[MAXE], nxt[MAXE];
int ecnt = 0;

void add_edge(int u, int v, int c) {
    to[ecnt] = v;
    cost[ecnt] = c;
    nxt[ecnt] = head[u];
    head[u] = ecnt++;
}

/* 優先度付きキュー（二分ヒープ） */
typedef struct { int d; int v; } Item;
Item heap[MAXE + 1];
int hsize = 0;

void push(int d, int v) {
    int i = hsize++;
    while (i > 0) {
        int p = (i - 1) / 2;
        if (heap[p].d <= d) break;
        heap[i] = heap[p];
        i = p;
    }
    heap[i].d = d;
    heap[i].v = v;
}

Item pop(void) {
    Item top = heap[0];
    Item last = heap[--hsize];
    int i = 0;
    while (1) {
        int c = 2 * i + 1;
        if (c >= hsize) break;
        if (c + 1 < hsize && heap[c + 1].d < heap[c].d) c++;
        if (heap[c].d >= last.d) break;
        heap[i] = heap[c];
        i = c;
    }
    heap[i] = last;
    return top;
}

int d[MAXV];

int main(void) {
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) head[i] = -1;

    for (int i = 0; i < n; i++) {
        int u, k;
        scanf("%d %d", &u, &k);
        for (int j = 0; j < k; j++) {
            int v, c;
            scanf("%d %d", &v, &c);
            add_edge(u, v, c);
        }
    }

    for (int i = 0; i < n; i++) d[i] = INF;
    d[0] = 0;
    push(0, 0);

    while (hsize > 0) {
        Item cur = pop();
        int u = cur.v;
        if (cur.d > d[u]) continue;   /* 古い情報は読み飛ばす */

        for (int e = head[u]; e != -1; e = nxt[e]) {
            int v = to[e];
            if (d[u] + cost[e] < d[v]) {
                d[v] = d[u] + cost[e];
                push(d[v], v);
            }
        }
    }

    for (int i = 0; i < n; i++) printf("%d %d\n", i, d[i]);
    return 0;
}
```

:::warning[よくあるミス]
- `heap[]` を頂点数 `MAXV` で確保して RE（ヒープには最大で**辺の数 + 1** 個入る）
- `heap[]` などの大きな配列を `main` の中に置いて RE（**グローバル変数**にする）
- 古い情報を読み飛ばさずに TLE（`if (cur.d > d[u]) continue;` を忘れない）
:::

:::tip[ALDS1_12_B にもそのまま使える]
ALDS1_12_C のコードは入出力形式が同じなので、ALDS1_12_B に提出しても AC になります。
小さい問題も大きい問題も解ける「ヒープ版」を、自分の道具として持っておきましょう。
:::
