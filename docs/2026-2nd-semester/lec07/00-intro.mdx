# 第7回: 総合演習（自習形式）

今回は新しい内容には進まず、これまで（第2回〜第6回）に学んだ内容の**練習問題**に、自分のペースで取り組む回です。

## 今回の目標

1. 前回課題（ダイクストラ法）の解法を確認する
2. 確認クイズで、後期に学んだ用語と考え方を振り返る
3. AOJ の問題を通して、学んだアルゴリズムを**自分の力で使える**ようにする

## 進め方

:::tip[おすすめの進め方]
1. まず [前回課題解説](./review) を読み、ALDS1_12_B / C を確認する
2. [確認クイズ](./quiz) で知識を振り返る（苦手な回が見つかったら、その回の資料に戻る）
3. 下の問題一覧から、**興味のある問題・苦手な回の問題**を選んで解く
4. 詰まったら、まず**ヒント**を開く。それでも分からなければ**解答例**を見て、理解してから自分で書き直す
5. AOJ に提出して **AC** を確認する
:::

:::info[今回は課題はありません]
今回の問題はすべて自習用です。提出の義務はありませんが、できるだけ多く AC を目指してみましょう。
分からないところは、授業中に講師に聞くか、Slack で質問してください。
:::
