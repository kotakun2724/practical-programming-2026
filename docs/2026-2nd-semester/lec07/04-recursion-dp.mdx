# 演習: 再帰・分割統治・DP

第3回（再帰と分割統治法）と第4回（動的計画法）の内容を使う問題です。

## ALDS1_5_D: The Number of Inversions ★★

[問題ページ（ALDS1_5_D）](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=ALDS1_5_D)

### 問題の概要

数列 `A` の**反転数**（`i < j` かつ `A[i] > A[j]` となるペアの数）を求めてください。
これは、バブルソートで並べ替えたときの交換回数と同じです。

- `1 <= n <= 200000`
- 要素はすべて異なる

### 考え方

すべてのペアを調べると `O(n^2)` になり、`n = 200000` では間に合いません。

<details>
<summary>ヒント</summary>

第3回の**マージソート**を利用します。左半分と右半分をマージするとき、
右側の要素 `a[j]` を先に取り出す場合、**左側に残っている要素はすべて `a[j]` より大きい**ので、
その個数（`mid - i` 個）だけ反転があります。

```
左: [2 5 8]   右: [1 3 9]
     ^i            ^j
1 を取り出す → 左に残っている 2, 5, 8 の3個はすべて 1 より大きい → 反転 +3
```

これをマージソートの途中で数えるだけで、`O(n log n)` で求まります。

</details>

<details>
<summary>解答例（C）</summary>

```c
#include <stdio.h>

int a[200000];
int tmp[200000];

/* a[left..right-1] をソートし、その中の反転数を返す */
long long merge_count(int left, int right) {
    if (right - left <= 1) return 0;
    int mid = (left + right) / 2;
    long long cnt = merge_count(left, mid) + merge_count(mid, right);

    int i = left, j = mid, k = left;
    while (i < mid && j < right) {
        if (a[i] <= a[j]) {
            tmp[k++] = a[i++];
        } else {
            cnt += mid - i;   /* 左側に残っている mid - i 個は a[j] より大きい */
            tmp[k++] = a[j++];
        }
    }
    while (i < mid) tmp[k++] = a[i++];
    while (j < right) tmp[k++] = a[j++];
    for (int t = left; t < right; t++) a[t] = tmp[t];
    return cnt;
}

int main(void) {
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);
    printf("%lld\n", merge_count(0, n));
    return 0;
}
```

:::warning[答えは long long]
反転数は最大で `n(n-1)/2 ≈ 2 × 10^10` になり、`int` には収まりません。`long long` を使いましょう。
:::

</details>

## DPL_1_B: 0-1 Knapsack Problem ★★

[問題ページ（DPL_1_B）](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=DPL_1_B)

### 問題の概要

価値 `v_i`、重さ `w_i` の品物が `N` 個あります。重さの合計が `W` 以下になるように品物を選ぶとき（各品物は1個まで）、
価値の合計の最大値を求めてください。

- `1 <= N <= 100`
- `1 <= W <= 10000`

### 考え方

すべての選び方は `2^N` 通りあり、`N = 100` では調べきれません。第4回の**部分和の DP** と同じように考えます。

<details>
<summary>ヒント</summary>

`dp[i][j]` =「品物 `1..i` の中から、重さの合計が `j` 以下になるように選んだときの価値の最大値」とします。

品物 `i` について「選ばない」「選ぶ」の2通りを考えます。

| 選び方 | 値 |
|:---|:---|
| 品物 `i` を選ばない | `dp[i-1][j]` |
| 品物 `i` を選ぶ（`j >= w_i` のとき） | `dp[i-1][j - w_i] + v_i` |

この大きい方が `dp[i][j]` です。答えは `dp[N][W]`、計算量は `O(NW)` です。

</details>

<details>
<summary>解答例（C）</summary>

```c
#include <stdio.h>

int v[101], w[101];
int dp[101][10001];   /* dp[i][j]: 品物 1..i から、重さの合計 j 以下で選んだときの価値の最大 */

int main(void) {
    int N, W;
    scanf("%d %d", &N, &W);
    for (int i = 1; i <= N; i++) scanf("%d %d", &v[i], &w[i]);

    for (int i = 1; i <= N; i++) {
        for (int j = 0; j <= W; j++) {
            dp[i][j] = dp[i - 1][j];                          /* 品物 i を選ばない */
            if (j >= w[i] && dp[i - 1][j - w[i]] + v[i] > dp[i][j]) {
                dp[i][j] = dp[i - 1][j - w[i]] + v[i];        /* 品物 i を選ぶ */
            }
        }
    }
    printf("%d\n", dp[N][W]);
    return 0;
}
```

:::tip[大きな配列はグローバルに]
`dp[101][10001]` は約 4MB です。第4回の LCS と同じく、グローバル変数にしましょう。
:::

</details>

## ALDS1_10_B: Matrix Chain Multiplication ★★★

[問題ページ（ALDS1_10_B）](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=ALDS1_10_B)

### 問題の概要

`n` 個の行列 `M_1 M_2 ... M_n` の積を計算します。`M_i` は `r_i` 行 `c_i` 列です。
掛ける順番（かっこの付け方）によって、必要なスカラーの掛け算の回数が変わります。その最小値を求めてください。

- `1 <= n <= 100`
- `1 <= r_i, c_i <= 100`

`a × b` 行列と `b × c` 行列の積には、`a × b × c` 回の掛け算が必要です。

### 考え方

かっこの付け方は非常に多く（`n` に対して指数的に増える）、すべて試すことはできません。

<details>
<summary>ヒント</summary>

`M_i` の行数・列数を `p[i-1] × p[i]` と書き、
`dp[i][j]` =「`M_i ... M_j` の積に必要な最小の掛け算回数」とします。

最後に掛ける位置 `k`（`(M_i ... M_k)(M_{k+1} ... M_j)` と分ける）をすべて試します。

```
dp[i][j] = min( dp[i][k] + dp[k+1][j] + p[i-1] × p[k] × p[j] )   （i <= k < j）
dp[i][i] = 0
```

`dp[i][j]` を計算するには、より**短い区間**の値が必要です。そこで、区間の長さが短い順に計算します（**区間 DP**）。
計算量は `O(n^3)` です。

</details>

<details>
<summary>解答例（C）</summary>

```c
#include <stdio.h>

int p[101];
int dp[101][101];   /* dp[i][j]: 行列 M_i ... M_j の積に必要な最小の掛け算回数 */

int main(void) {
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%d %d", &p[i - 1], &p[i]);   /* M_i は p[i-1] × p[i] */

    for (int len = 2; len <= n; len++) {          /* 区間の長さが短い順に */
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            dp[i][j] = 2000000000;
            for (int k = i; k < j; k++) {         /* (M_i..M_k)(M_k+1..M_j) に分ける */
                int c = dp[i][k] + dp[k + 1][j] + p[i - 1] * p[k] * p[j];
                if (c < dp[i][j]) dp[i][j] = c;
            }
        }
    }
    printf("%d\n", dp[1][n]);
    return 0;
}
```

サンプル入力（6個の行列）の答えは **15125** です。

</details>
