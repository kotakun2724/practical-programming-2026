確認クイズ

後期に学んだ内容を、クイズ形式で振り返ります。まず自分で答えを考えてから、解答を開いてください。 間違えた問題は、括弧内の回の資料を読み直しましょう。

Q1. 計算量（第2回）​

次のプログラムの計算量を、n を使ってビッグオー記法で答えてください。

/* (a) */
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)
        if (a[i] > a[j]) cnt++;

/* (b) */
int lo = 0, hi = n;
while (hi - lo > 1) {
    int mid = (lo + hi) / 2;
    if (a[mid] <= x) lo = mid;
    else hi = mid;
}
解答
  • (a) O(n^2): 内側のループは合計 n(n-1)/2 回まわります。
  • (b) O(log n): 1回ごとに範囲が半分になる二分探索です。

Q2. 計算量の見積もり（第2回）​

n = 100000 のとき、O(n^2) と O(n log n) のアルゴリズムはそれぞれ間に合うでしょうか。 （1秒間に約 10^8 回の計算ができるとします）

解答
  • O(n^2): 10^10 回 → 間に合わない（約100秒）
  • O(n log n): 約 100000 × 17 ≈ 1.7 × 10^6 回 → 間に合う

入力の大きさを見て、使えるアルゴリズムを選ぶのが大切です。

Q3. ソートと探索（第2回・第3回）​

次の中から、正しいものをすべて選んでください。

  1. バブルソートの計算量は O(n^2) である
  2. 二分探索は、ソートされていない配列でも使える
  3. マージソートの計算量は、最悪の場合でも O(n log n) である
  4. クイックソートの計算量は、最悪の場合でも O(n log n) である
解答

正しいのは 1 と 3 です。

  • 2: 二分探索は、配列がソート済みであることが前提です。
  • 4: クイックソートは、平均は O(n log n) ですが、ピボットの選び方が悪いと最悪 O(n^2) になります。

Q4. 再帰とスタック（第3回）​

次の関数で f(4) を呼ぶと、何が返るでしょうか。また、再帰関数に必ず必要な2つの要素は何でしょうか。

int f(int n) {
    if (n == 0) return 1;
    return 2 * f(n - 1);
}
解答

f(4) = 2 × f(3) = 2 × 2 × f(2) = ... = 2^4 = 16 です。

再帰関数に必要なのは、

  • ベースケース（n == 0 のときのように、再帰せずに答えを返す場合）
  • 再帰ステップ（より小さい問題 f(n - 1) を呼び出す部分）

の2つです。ベースケースがないと、無限に呼び出してスタックオーバーフローになります。

Q5. スタックとキュー（第3回・第5回・第6回）​

次のデータ構造と、それを使うアルゴリズムを正しく組み合わせてください。

データ構造アルゴリズム
(a) スタック(ア) ダイクストラ法
(b) キュー(イ) 深さ優先探索（DFS）
(c) 優先度付きキュー(ウ) 幅優先探索（BFS）
解答

(a)-(イ)、(b)-(ウ)、(c)-(ア) です。

データ構造取り出し順アルゴリズム
スタック後入れ先出し（LIFO）DFS（再帰でも書ける）
キュー先入れ先出し（FIFO）BFS
優先度付きキュー小さい順ダイクストラ法

Q6. メモ化と DP（第4回）​

フィボナッチ数を単純な再帰で計算すると遅いのはなぜでしょうか。また、メモ化するとなぜ速くなるのでしょうか。

解答

単純な再帰では、fib(n - 2) などの同じ計算が何度も繰り返されるため、計算量が指数関数的（約 O(1.6^n)）になります。

メモ化では、一度計算した値を配列に保存し、2回目からは保存した値を返すので、 fib(0) 〜 fib(n) を1回ずつ計算するだけで済み、O(n) になります。

Q7. DFS と BFS（第5回）​

迷路で「スタートからゴールまでの最小の手数」を求めたいとき、DFS と BFS のどちらを使うべきでしょうか。

解答

BFS です。BFS は始点から近い順に頂点を訪れるので、最初にゴールに着いたときの距離が最短（辺の本数が最小）になります。 DFS は行けるところまで深く進むので、最初に見つかった経路が最短とは限りません。

Q8. ダイクストラ法（第6回）​

ダイクストラ法が正しく動かないのは、どのようなグラフでしょうか。

解答

負の重みの辺があるグラフです。

ダイクストラ法は「未確定の頂点のうち最小のものは、これ以上短くならない」という性質を使っています。 負の辺があると、あとから別の経路で距離が短くなることがあり、この性質が崩れます。 その場合は、ベルマン–フォード法（GRL_1_B）などを使います。
