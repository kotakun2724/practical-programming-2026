# 練習問題

重み付きグラフとダイクストラ法を、実際に手を動かして確かめましょう。

## 練習 1: ダイクストラ法を手で追う

次の無向グラフで、頂点 `0` から各頂点への最短距離を、ダイクストラ法の手順どおりに表を埋めて求めてください。

```
        4
   0 ------- 1
   |       / |
 1 |    2 /  | 1
   |     /   |
   2 ------- 3
        5
```

| ステップ | 確定する頂点 | d[0] | d[1] | d[2] | d[3] |
|:---|:---|:---|:---|:---|:---|
| 初期状態 | - | 0 | ∞ | ∞ | ∞ |
| 1 | ? | ? | ? | ? | ? |
| 2 | ? | ? | ? | ? | ? |
| 3 | ? | ? | ? | ? | ? |
| 4 | ? | ? | ? | ? | ? |

<details>
<summary>解答</summary>

| ステップ | 確定する頂点 | d[0] | d[1] | d[2] | d[3] |
|:---|:---|:---|:---|:---|:---|
| 初期状態 | - | **0** | ∞ | ∞ | ∞ |
| 1 | 0（距離 0） | **0** | 4 | 1 | ∞ |
| 2 | 2（距離 1） | **0** | 3 | **1** | 6 |
| 3 | 1（距離 3） | **0** | **3** | **1** | 4 |
| 4 | 3（距離 4） | **0** | **3** | **1** | **4** |

答えは `d = [0, 3, 1, 4]` です。
`0 → 1` は直接行くと 4 ですが、`0 → 2 → 1` なら 3 なので短くなります。

</details>

## 練習 2: 経路を復元する

ダイクストラ法で求まるのは「距離」だけです。**実際にどの頂点を通ったか**も出力できるようにしてください。

ヒント: 緩和で `d[v]` を更新したときに、「`v` の1つ前の頂点は `u`」を `prev[v]` に記録します。

```c
int prev[MAXV];   /* 始点は -1 */

/* 緩和の部分 */
if (d[u] + w < d[v]) {
    d[v] = d[u] + w;
    // ここを実装
}

/* 始点から t までの経路を出力する */
void print_path(int t) {
    // ここを実装
}
```

<details>
<summary>解答例</summary>

```c
/* 緩和の部分 */
if (d[u] + w < d[v]) {
    d[v] = d[u] + w;
    prev[v] = u;
}

/* 始点から t までの経路を出力する */
void print_path(int t) {
    int path[MAXV], len = 0;
    for (int v = t; v != -1; v = prev[v]) {
        path[len++] = v;          /* t から始点へ逆向きにたどる */
    }
    for (int i = len - 1; i >= 0; i--) {
        printf("%d%s", path[i], i > 0 ? " -> " : "\n");
    }
}
```

`prev[]` は始点だけ `-1` にしておきます。練習1のグラフで `print_path(3)` を呼ぶと、

```
0 -> 2 -> 1 -> 3
```

と出力されます。終点から始点へ逆向きにたどってから、逆順に出力するのがポイントです。
再帰で `print_path(prev[t])` を先に呼んでから `t` を出力する書き方もできます（第3回の再帰の応用）。

</details>

## 練習 3: 負の辺があるとどうなるか

次の有向グラフで、頂点 `0` からダイクストラ法を実行すると、`d[1]` はいくつになるでしょうか。
また、本当の最短距離はいくつでしょうか。

```
0 → 1 : 2
0 → 2 : 3
2 → 1 : -2
```

<details>
<summary>解答</summary>

ダイクストラ法では、

1. 頂点 `0` を確定（`d[1] = 2`, `d[2] = 3`）
2. 未確定で最小の頂点 `1`（距離 2）を確定
3. 頂点 `2`（距離 3）を確定。`2 → 1` で `d[1]` を 1 にしたいが、`1` はもう確定済み

となり、`d[1] = 2` と答えてしまいます。本当の最短距離は `0 → 2 → 1` の **3 + (-2) = 1** です。

「最小の頂点はもう短くならない」という前提が、負の辺があると崩れるためです。
負の辺があるグラフでは**ベルマン–フォード法**（推奨課題 GRL_1_B）を使います。

</details>

## AOJ ALDS1_12_B: Single Source Shortest Path I

`n <= 100` なので、隣接行列 + `O(V^2)` のダイクストラ法で解けます。[ダイクストラ法](./dijkstra) の解答例を参考にしてください。

- 頂点番号は `0..n-1`、始点は `0`
- 重みが `0` の辺もあるので、「辺なし」は `-1` などで区別する

[問題ページ（ALDS1_12_B）](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=ALDS1_12_B)

## AOJ ALDS1_12_C: Single Source Shortest Path II

`n <= 10000`, `|E| < 500000` なので、隣接リスト + 二分ヒープが必要です。[優先度付きキューによる高速化](./priority-queue) の解答例を参考にしてください。

- ヒープの大きさは**辺の数 + 1** 以上
- 取り出した距離が `d[u]` より大きければ読み飛ばす
