# 重み付きグラフと最短経路

## 重み付きグラフ

辺に**重み（コスト）** がついたグラフを**重み付きグラフ**といいます。

| 例 | 頂点 | 辺の重み |
|:---|:---|:---|
| 路線図 | 駅 | 所要時間・運賃 |
| 道路地図 | 交差点 | 距離 |
| ネットワーク | ルーター | 通信の遅延 |

**最短経路問題**とは、始点から各頂点への「通る辺の重みの合計」が最小になる経路（とその長さ）を求める問題です。
特に「1つの始点から全頂点への最短距離」を求める問題を**単一始点最短経路問題**といいます。

## BFS ではうまくいかない例

```
      5
  A ----- B
   \     /
  1 \   / 1
     \ /
      C
```

`A` から BFS をすると、`B` には「辺 1 本」で行けるので先に訪問済みになり、距離 5 で確定してしまいます。
しかし実際には `A → C → B` の **1 + 1 = 2** が最短です。

:::important[辺の本数が少ない ≠ 重みの合計が小さい]
BFS が最短距離を求められたのは、**すべての辺の重みが 1** だったからです。
重みがばらばらなときは、**「今の時点で一番近い頂点」から順に確定させる**必要があります。これがダイクストラ法です。
:::

## 重み付きグラフの表現

### 隣接行列

`M[u][v]` に辺の重みを入れます。重みが `0` の辺もあり得るので、「辺がない」は `-1` などの値で区別します。

```c
int M[100][100];

for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++) M[i][j] = -1;   /* -1: 辺なし */

M[u][v] = c;   /* u → v に重み c の辺 */
```

### 隣接リスト

行き先 `to[]` と一緒に、重み `cost[]` も持たせます。

```c
int head[MAXV];                       /* head[u]: u から出る最初の辺の番号（なければ -1） */
int to[MAXE], cost[MAXE], nxt[MAXE];  /* 辺 e の行き先・重み・u から出る次の辺 */
int ecnt = 0;

void add_edge(int u, int v, int c) {
    to[ecnt] = v;
    cost[ecnt] = c;
    nxt[ecnt] = head[u];
    head[u] = ecnt++;
}

/* u から出る辺をすべて見る */
for (int e = head[u]; e != -1; e = nxt[e]) {
    int v = to[e], c = cost[e];
    /* ... */
}
```

## 緩和（relaxation）

最短経路アルゴリズムの基本操作は、次の**緩和**です。

> 「`u` までの距離 `d[u]` + 辺 `u → v` の重み」が今の `d[v]` より小さければ、`d[v]` を更新する

```c
if (d[u] + w < d[v]) {
    d[v] = d[u] + w;
}
```

最初は `d[始点] = 0`、それ以外は `d[v] = INF`（とても大きな値）にしておき、緩和を繰り返して `d[]` を小さくしていきます。

:::tip[INF の選び方]
`INF` は「答えとしてあり得る最大値」より大きく、かつ `d[u] + w` を計算しても **`int` があふれない**値にします。
ALDS1_12 の場合、最短距離は最大でも `100000 × 9999 ≈ 10^9` 程度なので、`int` の範囲（約 `2.1 × 10^9`）に収まります。
:::

## 負の重みについて

ダイクストラ法は **重みが 0 以上** のときにだけ正しく動きます。
負の重みの辺がある場合は、**ベルマン–フォード法**などの別のアルゴリズムを使います（推奨課題 GRL_1_B）。
