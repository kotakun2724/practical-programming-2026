## 今回学ぶこと

### 1. 重み付きグラフ

辺に「距離」「時間」「運賃」などの**重み（コスト）** がついたグラフです。

```
      5
  A ----- B
   \     /
  1 \   / 1
     \ /
      C
```

`A → B` は直接行くとコスト 5、`C` を経由するとコスト 2 です。**辺の本数が少ない経路が最短とは限りません**。

### 2. ダイクストラ法

始点からの距離が**確定していない頂点のうち最小のもの**を1つ選んで確定し、そこから出る辺で他の頂点の距離を更新する、を繰り返します。

```c
d[s] = 0;
for (n 回) {
    u = 未確定の頂点のうち d[u] が最小のもの;
    u を確定;
    for (u の隣接頂点 v) {
        if (d[u] + w(u, v) < d[v]) d[v] = d[u] + w(u, v);   /* 緩和 */
    }
}
```

### 3. 優先度付きキュー

「最小のものを取り出す」を `O(log V)` で行えるデータ構造です。これを使うとダイクストラ法を大きなグラフでも高速に動かせます。
