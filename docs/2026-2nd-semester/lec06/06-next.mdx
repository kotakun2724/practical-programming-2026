### 各問題のヒント

#### ALDS1_12_B: Single Source Shortest Path I

`d[]` を `INF`、`d[0] = 0` で初期化し、「未確定で最小の頂点を確定 → 緩和」を `n` 回繰り返します。

```c
for (int step = 0; step < n; step++) {
    int u = -1;
    for (int i = 0; i < n; i++) {
        if (!done[i] && d[i] != INF && (u == -1 || d[i] < d[u])) u = i;
    }
    if (u == -1) break;
    done[u] = 1;
    for (int v = 0; v < n; v++) {
        if (M[u][v] != -1 && d[u] + M[u][v] < d[v]) d[v] = d[u] + M[u][v];
    }
}
```

#### ALDS1_12_C: Single Source Shortest Path II

隣接リスト（`head / to / cost / nxt`）でグラフを持ち、二分ヒープから距離の小さい順に取り出します。

```c
push(0, 0);
while (hsize > 0) {
    Item cur = pop();
    int u = cur.v;
    if (cur.d > d[u]) continue;
    for (int e = head[u]; e != -1; e = nxt[e]) {
        int v = to[e];
        if (d[u] + cost[e] < d[v]) {
            d[v] = d[u] + cost[e];
            push(d[v], v);
        }
    }
}
```

ALDS1_12_C のコードは ALDS1_12_B にもそのまま提出できます。両方で AC を確認してみましょう。

## 困ったときは

### よくあるエラー

| エラー | 原因 | 対処法 |
|:-------|:-------|:-----|
| WA | 頂点番号を `1..n` で扱っている | ALDS1_12 は `0..n-1`。ループの範囲を確認 |
| WA | 重み 0 の辺を「辺なし」と判定している | 「辺なし」は `-1` などで区別する |
| WA | `INF + c` がオーバーフローして負になった | `d[u] == INF` の頂点からは緩和しない |
| TLE | ALDS1_12_C で `O(V^2)` の実装を使った | 隣接リスト + 二分ヒープに切り替える |
| TLE | 古い情報を読み飛ばしていない | `if (cur.d > d[u]) continue;` を入れる |
| RE | ヒープの配列が小さい | ヒープは**辺の数 + 1** 以上確保する |
| RE | 大きな配列を `main` の中に置いた | グローバル変数にする |
