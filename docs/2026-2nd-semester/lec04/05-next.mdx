### 各問題のヒント

#### ALDS1_10_A: Fibonacci Number

初期値が数学の教科書と違う点に注意（`F(0)=1, F(1)=1`）。

```c
dp[0] = 1;
dp[1] = 1;
for (int i = 2; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];
}
```

#### ALDS1_10_C: Longest Common Subsequence

`dp[i][j]` = `X` の先頭 `i` 文字と `Y` の先頭 `j` 文字の LCS 長。

```c
if (X[i - 1] == Y[j - 1]) {
    dp[i][j] = dp[i - 1][j - 1] + 1;
} else {
    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
}
```

クエリが複数あるので、毎回 `dp` を適切に初期化してください。
