## 今回学ぶこと

### 1. メモ化（トップダウン）

再帰のまま、計算済みの結果を配列に覚えて再利用します。

```c
int memo[100];

int fib(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];  // すでに計算済み
    return memo[n] = fib(n - 1) + fib(n - 2);
}
```

### 2. 動的計画法（ボトムアップ）

小さい問題から順に答えを埋めていきます。

```c
int dp[100];
dp[0] = 0; dp[1] = 1;
for (int i = 2; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];
}
```
