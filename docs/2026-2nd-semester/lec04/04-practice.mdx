# 練習問題

メモ化と DP を、実際に手を動かして確かめましょう。

## 練習 1: フィボナッチをメモ化で実装する

`fib(n)` をメモ化再帰で実装してください（ここでは数学定義 `F(0)=0, F(1)=1`）。

```c
#include <stdio.h>
#include <string.h>

int memo[100];

int fib(int n) {
    // ここを実装
    return 0;
}

int main(void) {
    memset(memo, -1, sizeof(memo));
    printf("%d\n", fib(10));  // 55
    return 0;
}
```

<details>
<summary>解答例</summary>

```c
int fib(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    return memo[n] = fib(n - 1) + fib(n - 2);
}
```

</details>

## 練習 2: フィボナッチをボトムアップ DP で実装する

同じ問題を、ループで `dp` 配列を埋めて解いてください。

```c
int fib_dp(int n) {
    // ここを実装
    return 0;
}
```

<details>
<summary>解答例</summary>

```c
int fib_dp(int n) {
    if (n <= 1) return n;
    int dp[100];
    dp[0] = 0;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}
```

</details>

## 練習 3: 部分和を DP で判定する

配列 `a`（長さ `n`）の部分集合で和 `m` を作れるなら `1`、そうでなければ `0` を返す関数を書いてください。

```c
int can_make(int *a, int n, int m) {
    // ここを実装
    return 0;
}
```

<details>
<summary>解答例</summary>

```c
int can_make(int *a, int n, int m) {
    int dp[2001] = {0};
    dp[0] = 1;
    for (int i = 0; i < n; i++) {
        for (int j = m; j >= a[i]; j--) {
            if (dp[j - a[i]]) dp[j] = 1;
        }
    }
    return dp[m];
}
```

</details>

## AOJ ALDS1_10_A: Fibonacci Number

フィボナッチ数 `F(n)` を求めます。**定義に注意**: `F(0)=1, F(1)=1`。

### ヒント

```c
int dp[50];
dp[0] = 1;
dp[1] = 1;
for (int i = 2; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];
}
printf("%d\n", dp[n]);
```

## AOJ ALDS1_10_C: Longest Common Subsequence

2文字列の LCS 長を求めます。クエリが複数回来る点にも注意してください。

### ヒント

```c
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (X[i - 1] == Y[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1;
        else dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
    }
}
```

[問題ページ（ALDS1_10_C）](https://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=ALDS1_10_C)

:::tip[配列の初期化]
各クエリのたびに `dp` をゼロ初期化するか、`n+1` / `m+1` の範囲だけ確実に埋めるようにしましょう。
:::
