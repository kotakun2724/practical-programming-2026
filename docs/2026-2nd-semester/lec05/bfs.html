幅優先探索（BFS）

キュー​

BFS では キュー（queue） を使います。キューは FIFO（First In First Out: 先入れ先出し） のデータ構造で、 レジの行列のように先に並んだものから先に取り出されます。

データ構造取り出し順主な用途
スタック（第3回）後入れ先出し（LIFO）DFS、再帰
キュー先入れ先出し（FIFO）BFS

配列と2つの添字（head, tail）で簡単に実装できます。

int q[1000];
int head = 0, tail = 0;

void enqueue(int x) { q[tail++] = x; }
int  dequeue(void)  { return q[head++]; }
int  empty(void)    { return head == tail; }

考え方​

幅優先探索（Breadth-First Search, BFS） は、始点から近い順に頂点を訪れる探索です。

  1. 始点をキューに入れ、距離を 0 にする
  2. キューから頂点 u を取り出す
  3. u の隣接頂点のうち、まだ距離が決まっていないもの v に d[v] = d[u] + 1 を設定してキューに入れる
  4. キューが空になるまで 2〜3 を繰り返す
  1 --- 2 --- 5
  |     |
  3     4

1 から BFS:
距離0: 1
距離1: 2, 3
距離2: 4, 5
BFS は最短距離を求められる

BFS は近い頂点から順に確定させていくので、求めた d[v] は 始点から v への最短距離（通る辺の本数） になります。 DFS ではこの性質は成り立ちません。

AOJ ALDS1_11_C: Breadth First Search​

頂点 1 から各頂点への最短距離を出力します。到達できない頂点は -1 を出力します。

解答例（C）​

#include <stdio.h>

int n;
int M[101][101];
int d[101];
int q[101];

int main(void) {
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        int u, k;
        scanf("%d %d", &u, &k);
        for (int j = 0; j < k; j++) {
            int v;
            scanf("%d", &v);
            M[u][v] = 1;
        }
    }

    for (int i = 1; i <= n; i++) d[i] = -1;   /* -1: 未到達 */

    int head = 0, tail = 0;
    d[1] = 0;
    q[tail++] = 1;

    while (head < tail) {
        int u = q[head++];
        for (int v = 1; v <= n; v++) {
            if (M[u][v] && d[v] == -1) {
                d[v] = d[u] + 1;
                q[tail++] = v;
            }
        }
    }

    for (int u = 1; u <= n; u++) {
        printf("%d %d\n", u, d[u]);
    }
    return 0;
}
d 配列が訪問済みフラグを兼ねる

d[v] == -1 なら未訪問、それ以外なら訪問済みです。 別に visited 配列を用意しなくても、距離の配列だけで管理できます。

DFS と BFS の比較​

項目DFSBFS
使うデータ構造スタック（再帰）キュー
進み方行けるところまで深く近いところから順に
最短距離（辺の本数）求められない求められる
計算量（隣接リスト）O(V + E)O(V + E)
向いている問題連結判定、全列挙、閉路検出最短手数、迷路の最短経路
