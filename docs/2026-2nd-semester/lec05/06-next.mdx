### 各問題のヒント

#### ALDS1_11_A: Graph

入力の `u k v1 ... vk` を読みながら `M[u][vi] = 1` とし、最後に行列を空白区切りで出力します。

#### ALDS1_11_B: Depth First Search

```c
void dfs(int u) {
    color[u] = 1;
    d[u] = ++t;
    for (int v = 1; v <= n; v++) {
        if (M[u][v] && color[v] == 0) dfs(v);
    }
    color[u] = 2;
    f[u] = ++t;
}
```

`main` では `for (u = 1; u <= n; u++) if (color[u] == 0) dfs(u);` で全頂点をカバーします。

#### ALDS1_11_C: Breadth First Search

`d[]` を `-1` で初期化し、頂点 `1` をキューに入れてから BFS します。

```c
while (head < tail) {
    int u = q[head++];
    for (int v = 1; v <= n; v++) {
        if (M[u][v] && d[v] == -1) {
            d[v] = d[u] + 1;
            q[tail++] = v;
        }
    }
}
```

## 困ったときは

### よくあるエラー

| エラー | 原因 | 対処法 |
|:-------|:-----|:-------|
| WA | 到達できない頂点を DFS していない | 未訪問の全頂点から DFS を開始する |
| WA | 時刻のカウントずれ | 発見時・完了時の両方で `++t` しているか確認 |
| WA | 未到達の頂点を `-1` にしていない | `d[]` を `-1` で初期化しているか確認 |
| RE | 配列の添字範囲外 | 頂点番号 `1..n` に対して `n + 1` 以上確保しているか確認 |
| TLE / RE | 頂点数が多い問題で隣接行列を使った | 隣接リストに切り替える（ALDS1_11_D など） |
