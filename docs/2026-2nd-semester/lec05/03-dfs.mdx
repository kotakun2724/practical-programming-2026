# 深さ優先探索（DFS）

## 考え方

**深さ優先探索（Depth-First Search, DFS）** は、

1. 今いる頂点から、まだ訪れていない隣接頂点へ進む
2. 進めなくなったら、1つ前の頂点に戻る（**バックトラック**）
3. すべての頂点を訪れるまで繰り返す

という探索です。迷路を「右手を壁につけて」進むイメージに近いです。

```
  1 --- 2 --- 5
  |     |
  3     4

1 から DFS（小さい番号を優先）:
1 → 2 → 4（行き止まり、2 に戻る）→ 5（行き止まり、2→1 に戻る）→ 3
訪問順: 1, 2, 4, 5, 3
```

## 再帰による実装

「戻る」動作はコールスタックが自動でやってくれるので、**再帰**で自然に書けます。

```c
#include <stdio.h>

int n;
int M[101][101];
int visited[101];

void dfs(int u) {
    visited[u] = 1;
    printf("%d\n", u);          /* 訪問した頂点を出力 */
    for (int v = 1; v <= n; v++) {
        if (M[u][v] && !visited[v]) {
            dfs(v);
        }
    }
}
```

:::tip[第3回とのつながり]
DFS は「再帰 = コールスタック」の典型的な応用です。
再帰を使わずに、自前の**スタック**で書き換えることもできます。
:::

## 発見時刻と完了時刻（AOJ ALDS1_11_B）

ALDS1_11_B では、各頂点について

- `d[u]`: 初めて訪れた時刻（**発見時刻**）
- `f[u]`: 隣接頂点をすべて調べ終えた時刻（**完了時刻**）

を記録して出力します。時刻は 1 から始まり、発見・完了のたびに 1 ずつ進みます。

### 解答例（C）

```c
#include <stdio.h>

int n;
int M[101][101];
int color[101];   /* 0: 未訪問, 1: 訪問中, 2: 完了 */
int d[101], f[101];
int t = 0;

void dfs(int u) {
    color[u] = 1;
    d[u] = ++t;
    for (int v = 1; v <= n; v++) {
        if (M[u][v] && color[v] == 0) {
            dfs(v);
        }
    }
    color[u] = 2;
    f[u] = ++t;
}

int main(void) {
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        int u, k;
        scanf("%d %d", &u, &k);
        for (int j = 0; j < k; j++) {
            int v;
            scanf("%d", &v);
            M[u][v] = 1;
        }
    }

    /* つながっていない頂点があるので、未訪問の頂点から順に DFS する */
    for (int u = 1; u <= n; u++) {
        if (color[u] == 0) dfs(u);
    }

    for (int u = 1; u <= n; u++) {
        printf("%d %d %d\n", u, d[u], f[u]);
    }
    return 0;
}
```

:::warning[全頂点からの開始を忘れない]
始点 `1` から到達できない頂点もあります。`for (u = 1..n)` で**未訪問の頂点から改めて DFS** しないと、
`d[u]`, `f[u]` が 0 のままの頂点が出て WA になります。
:::

## 計算量

| 表現 | 計算量 |
|:---|:---|
| 隣接行列 | `O(V^2)`（各頂点で `n` 個の候補を調べる） |
| 隣接リスト | `O(V + E)` |

## DFS でできること

- 連結かどうかの判定（ある頂点から全頂点に行けるか）
- 連結成分の個数を数える
- サイクル（閉路）の検出
- 迷路の経路探索、全通りの列挙
