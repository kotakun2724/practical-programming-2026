# グラフの基本と表現方法

## グラフの用語

| 用語 | 意味 |
|:---|:---|
| 頂点（vertex / node） | 点。路線図なら駅、SNS ならユーザー |
| 辺（edge） | 頂点どうしのつながり |
| 無向グラフ | 辺に向きがない（`u - v` は双方向） |
| 有向グラフ | 辺に向きがある（`u → v` は一方通行） |
| 隣接 | 辺で直接つながっていること |
| 次数 | 頂点につながっている辺の本数 |
| パス（経路） | 辺をたどって頂点を移動する道筋 |

```
無向グラフ          有向グラフ
  1 --- 2            1 ---> 2
  |     |            |      |
  3 --- 4            v      v
                     3 ---> 4
```

## 表現方法 1: 隣接行列

`n × n` の2次元配列 `M` を用意し、`u` から `v` へ辺があれば `M[u][v] = 1` とします。

```
有向グラフ: 1→2, 1→4, 2→4, 4→3

      1 2 3 4
   1 [0 1 0 1]
   2 [0 0 0 1]
   3 [0 0 0 0]
   4 [0 0 1 0]
```

```c
int M[101][101];   /* 頂点番号 1..n を使う */

M[1][2] = 1;       /* 辺 1 → 2 を追加 */
/* 無向グラフなら M[2][1] = 1; も追加する */
```

## 表現方法 2: 隣接リスト

各頂点ごとに「つながっている頂点の一覧」を持ちます。

```
1: 2 4
2: 4
3:
4: 3
```

C 言語では、配列で簡易的に書けます。

```c
int adj[101][101];  /* adj[u][i] = u の i 番目の隣接頂点 */
int deg[101];       /* deg[u]    = u の隣接頂点の数     */

void add_edge(int u, int v) {
    adj[u][deg[u]++] = v;
}
```

## どちらを使うか

| 項目 | 隣接行列 | 隣接リスト |
|:---|:---|:---|
| メモリ | `O(V^2)` | `O(V + E)` |
| 「`u` と `v` はつながっているか」 | `O(1)` | `O(次数)` |
| 隣接頂点を全部見る | `O(V)` | `O(次数)` |
| 向いている場面 | 頂点数が小さい（`V <= 1000` 程度） | 頂点数が大きく辺が少ない |

:::tip[AOJ ALDS1_11 は隣接行列で OK]
ALDS1_11 の問題は `n <= 100` なので、実装が簡単な**隣接行列**で十分です。
頂点が `10^5` 個のような問題では隣接リストが必要になります。
:::

## AOJ ALDS1_11_A: Graph（隣接リスト → 隣接行列）

隣接リスト形式で与えられた有向グラフを、隣接行列にして出力する問題です。

### 入力形式

```
n
u k v1 v2 ... vk    （n 行。頂点 u の隣接頂点が k 個）
```

### 解答例（C）

```c
#include <stdio.h>

int M[101][101];

int main(void) {
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        int u, k;
        scanf("%d %d", &u, &k);
        for (int j = 0; j < k; j++) {
            int v;
            scanf("%d", &v);
            M[u][v] = 1;
        }
    }

    for (int u = 1; u <= n; u++) {
        for (int v = 1; v <= n; v++) {
            if (v > 1) printf(" ");
            printf("%d", M[u][v]);
        }
        printf("\n");
    }
    return 0;
}
```

:::note[頂点番号は 1 から]
ALDS1_11 の頂点番号は `1..n` です。配列は `n + 1` 個以上確保して、`0` 番は使わないと考えると楽です。
:::
