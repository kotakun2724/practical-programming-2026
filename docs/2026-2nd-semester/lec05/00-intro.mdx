## 今回学ぶこと

### 1. グラフとは

**頂点（ノード）** と、頂点どうしをつなぐ **辺（エッジ）** からなる構造です。
路線図、SNS の友人関係、Web ページのリンクなど、身近なものの多くがグラフで表せます。

```
  1 --- 2
  |     |
  3 --- 4 --- 5
```

### 2. 深さ優先探索（DFS）

行けるところまで深く進み、行き止まりになったら戻る探索です。

```c
void dfs(int u) {
    visited[u] = 1;
    for (int v = 1; v <= n; v++) {
        if (M[u][v] && !visited[v]) dfs(v);
    }
}
```

### 3. 幅優先探索（BFS）

始点に近い頂点から順に、同心円状に広げていく探索です。

```c
q[tail++] = s;  d[s] = 0;
while (head < tail) {
    int u = q[head++];
    for (int v = 1; v <= n; v++) {
        if (M[u][v] && d[v] == -1) {
            d[v] = d[u] + 1;
            q[tail++] = v;
        }
    }
}
```
